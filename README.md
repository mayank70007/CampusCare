# CampusCare

CampusCare is a voice-first campus assistant for students. It helps students report campus complaints, set reminders, check timetables, and discover campus events from one simple interface.

## What it solves

CampusCare makes it easier for students to communicate campus issues and access everyday campus information without switching between multiple systems.

## Tech stack

- React and Vite
- Tailwind CSS
- Node.js and Express
- MongoDB with Mongoose
- Gemini API for intent and complaint classification
- Web Speech API for voice input
